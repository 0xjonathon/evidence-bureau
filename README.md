# 有据事务所 · THE EVIDENCE BUREAU

GitHub 工程快照：本地运行、EdgeOne 导入构建及生产环境配置见 [部署说明](docs/GITHUB-DEPLOY.md)。人物动作优化仍在迭代，历史版本验收记录请按版本阅读。

一间只凭证据说话的侦探事务所。委托单放在访客面前的桌上，点击微光入口切到俯视，输入中文时由第一人称右手持笔逐笔写入，并可夹入多张截图。侦探在待机时托腮、敲桌；接单后自行取纸，放到一体仪器顶部扫描。面向访客的屏幕和浮窗同步显示调查事件；下方出纸后，侦探按结论盖章、画叉或写批注，再将报告放回原来的位置，最后弹出带来源的正文。

## 本地运行

需要 Node.js 22.12+（当前已在 Node.js 25 上验证）。

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:4173 。三维模型与字体不依赖外部 CDN。未配置密钥也能体验三个明确标注的离线示例；它们不是实时搜索。

真实查询：在根目录复制 `.env.example` 为 `.env`，在本地编辑器填入配置后重启服务。不要把密钥发到聊天或放进 `public/`。

| 变量 | 用途 |
| --- | --- |
| `TENCENTCLOUD_WSA_APIKEY` | 腾讯元宝搜索服务 API KEY，真实搜索必填 |
| `LLM_BASE_URL` | OpenAI 兼容的模型 API 基址（需包含供应商要求的 `/v1` 等前缀） |
| `LLM_API_KEY` / `LLM_MODEL` | 问题拆解、证据判断与复核 |
| `LLM_REVIEW_MODEL` | 可选，第二轮复核的模型名称；未填时为同一模型第二次调用，界面会如实标注 |
| `LLM_VISION_MODEL` | 可选，同一模型端点支持的视觉模型，用于截图文字提取 |
| `HOST` / `PORT` | 默认 `127.0.0.1:4173` |

元宝接入使用腾讯官方服务 API KEY 鉴权方式：`POST https://api.wsa.cloud.tencent.com/SearchPro`，请求 `{ "Query": "..." }`。不接受云 SecretId/SecretKey 代替服务 API KEY。官方指引：https://cloud.tencent.cn/document/product/1806/130615 。

`.env.example` 中的 DeepSeek 基址只是通用示例。当前本机已经按用户提供的配置接入阶跃 `step-3.7-flash`，分析、复核和截图识别共用该模型。阶跃启用了 JSON Mode、low 推理强度和 8192 token 输出上限，以保证结构化报告完整；这些参数仅存在本机配置中，密钥不会写入文档。工程不会替你注册或购买服务。

## 已实现

- 探员身份：首次进入领取工牌（编号、代号、军衔），令牌只存在你的浏览器，服务端只存哈希。案卷按探员保存在服务端，可从“案件档案”重新打开。
- 查证管线：原始命题、原始出处、反证分别检索；深度模式先检视已有线索、点名证据缺口，再追加最多两轮针对性搜索。来源按发布者类型分级；内容近乎相同的转载只算一个独立来源；引文按句子或词边界切分。
- 原文核对：对被引用的页面抓取全文（有 SSRF 防护：仅公网地址、逐跳校验重定向、大小和时间上限），引文在原页面中找到才标“原文已核对”，抓不到就如实标“仅摘要”，不影响结论。
- 探长批示与悬案：复核步骤产出红笔批注；结论为“无法判断”时给出“出现什么证据才能定论”，算作如实结案。
- 持续盯梢：在报告页登记邮箱，确认邮件后每天复查一次；只有结论出现实质变化才发邮件，降为“无法判断”只记录不发信，邮件内一键退订。需要配置 `RESEND_API_KEY`、`MAIL_FROM`、`CRON_SECRET`。
- 额度保护：每个探员每日调查次数、全月搜索预算（先预留、结束后退还未用次数）、相同说法 24 小时案卷调阅（仅当模型明确判定为非时效类）。
- V5 人物与动作：两个完整 VRoid beta 标准模型（107 / 129 骨骼、各 54 标准人体映射关节），保留原始手与五指骨骼；侦探适配黑发、眼镜、蓝衣与红领结。Quaternius CC0 坐姿保留为腿部底层，上半身由有活动范围的原生骨骼与物件接触动作驱动。
- V8 桌面交互：移除笔记本、独立键盘、分离的打印机和扫描仪；侦探左侧为 Blender 建模的一体仪器，右侧为笔和印章。加宽桌面并给座位留出凹口；仪器后移以留出前臂空间，真实骨骼手与物件在同一个深度场景渲染。
- V8 接触约束：Rapier 固定步长、纸张体积扫掠、CCD、共享设备尺寸；原生双骨 IK、受限指关节、肩部与前臂旋转范围、四段渐进前臂扭转蒙皮；抬起、平移、放下、释放分阶段进行。取纸、批注和归还使用同一物件位置驱动接触，快进也推进物理世界。
- V8 手写：本地 Hanzi Writer / Make Me a Hanzi 笔画路径驱动中文墨迹和笔尖；输入法组合输入结束后才落笔，增删及多图移除同步。非中文字符使用本地字体回退。手机保留纸面输入，底部控件提供触控尺寸。
- 其余沿用：截图识别回填、流式阶段日志、Markdown 下载、档案和证据报告。

## 可信边界

搜索返回摘要；工程对报告引文尝试抓取原页核对，抓取失败的来源保留“仅摘要”状态。相关性分数不会被当成真假概率。

主流程把本次检索摘要切为不改字的连续片段，并给每段编号；模型只能选择该来源的片段编号，服务器再恢复原文，剔除伪造或跨来源编号。兼容旧报告时只接受可还原到摘要的原文片段；至少两个不同主机各有同方向的直接有效引用才允许确定支持或反驳结论；背景资料不能凑足这个门槛，同时检查引用关系与结论一致。不同域名不自动等于独立来源，模型同时被要求检查转载、同源与时间条件；自动判断仍可能出错，报告保留可核验材料。

仅做公开知识、科学传闻和作品线索；关键词初筛加模型受理判断用于限制时政、个人传闻和隐私请求。关键词规则不是完整审核系统；如要正式公开服务，需补充适合实际流量的审核、认证和账户额度措施。

默认仅监听本机。服务端密钥不下发浏览器，页面内容以 `textContent` 渲染，来源只允许 HTTP(S)，不接收用户指定的上游地址；同源检查、请求大小、并发数和每分钟提交次数均有限制。

## 检查与部署

部署到 Vercel：`vercel.json` 已配置构建（`npm run build` 把 three 复制到 `public/vendor`）、安全响应头、函数时长 300 秒和每日 Cron。需要在 Vercel 里添加 Upstash Redis 并设置环境变量；没有 Redis 时状态只在内存中，重启即丢。Hobby 档 Cron 每天最多一次，触发时刻会在一小时内浮动。大陆网络访问 `*.vercel.app` 不保证可用，请绑定自有域名并用手机流量实测。

```sh
npm run check
npm test
```

108 项测试覆盖证据判断、来源分级、转载识别、原文抓取与 SSRF、额度、鉴权、盯梢、动画几何与编排，全部使用模拟供应商，不消耗真实额度。另已完成元宝与阶跃的实网联调、三份真实报告和截图识别。当前 V5 人物、交互与文案检查见 `docs/visual-v5/VERIFICATION.md`；上一轮新增真实查询见 `docs/visual-v4/VERIFICATION.md`，早期联调见 `docs/real-queries/README.md`。

完整服务需要 Node.js 后端，不能只把 `public/` 放到静态托管中就获得真实搜索。可在支持 Node 的主机运行 `npm ci --omit=dev && npm start`，用 HTTPS 反向代理，设置 `HOST=0.0.0.0`，在部署平台注入环境变量。公开部署前需为服务添加鉴权和全局额度管理；当前限流是单进程体验级实现。附 `Dockerfile` 便于自托管。
