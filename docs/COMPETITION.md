## 实际查询演示

先在本地 `.env` 配置元宝搜索和分析模型，重启后确认右侧“元宝搜索已接入”。截图识别进阶演示还需配置同一端点可用的视觉模型。

推荐三个不涉及个人与时政的题目：

1. “金星的一天比一年长吗？请区分恒星日与太阳日。”展示带条件的结论。
2. “月球背面永远照不到阳光吗？”展示反证和概念区分。
3. “普通声波能穿过太空真空传播吗？”展示两个独立科学机构资料。

这三个题目必须**手动填写并点击递交委托**，不能点击页面底部“离线示例”冒充真实查询。真实查询的答案以当次搜索证据为准，不保证复现离线示例标签。

每段录屏包含：

- 委托单、递纸动作、调查终端中的实际查询词。
- 报告的结论、来源链接和证据边界。
- 打开至少一个来源，确认页面确实可访问。
- 展开“调查过程与查询记录”，显示元宝 RequestId（不要录到 .env 或密钥）。
- 下载 Markdown 报告留档。

截图查证：准备一张明确写有公开科学说法的自制截图 → 夹入截图 → 点击识别 → 核对并修改文字 → 递交。要展示识别不清时允许用户纠正，不能让图片中的文字直接控制调查指令。

深度调查：勾选后通常多查一轮。模型可能去掉重复查询，因此报告展示实际轮次；不要把动画阶段数当搜索调用数。持续盯梢未实现，本项目选择深度调查和截图查证两条进阶方向。
