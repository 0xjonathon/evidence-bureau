# V12.1 人物动作修复验收

此次修复使用当前原生人物骨架，不更换模型，也不靠缩放骨骼或移动手部顶点掩盖深度穿模。保留原有浅层指腹接触修正。

## 修复内容

- 从角色自带 Sitting_Idle_Loop 提取真实肘部弯曲平面，分别校准侦探和委托者。
- 用连续的双骨骼解析求解替换运行时七自由度位置搜索；固定一个肘部分支，手腕由前臂姿态推导，握笔、捏纸、盖章均保留骨骼长度。
- 工作切换时，原先托腮手的 forward/normal 在中间帧重合；现用始终正交的旋转轨迹，消除手掌翻向。
- 握物姿势从原有托腮/敲桌姿势连续混合，先混合接触点再闭合手指；手腕弯曲按握持权重和时间变化，避免拿笔瞬间跳变。
- 固定目标的解收敛后缓存，避免静止时持续搜索引起哆嗦。四元数归一化，所有转速按时间步长计算。
- 递交、取回、盖章后回位的目标与待机姿态连续衔接。撤回时先从仪器上方接近扫描台，手握住后纸张才移动。
- 缩短纸张向观众方向的过远搬运路线，避免强行拉直手臂；节奏从 1.8 倍调整为 1.2 倍。
- 固定坐姿的髋部位置，伸手由上半身前倾、侧倾完成，避免整个人平移、抬升后大腿穿进桌子。
- 取消与显示刷新率不匹配的 40 Hz 跳帧判断；不可见的委托者停止执行手臂求解。

- 为印戳球形握柄和锥形手柄加入真实指面碰撞代价，按实际蒙皮校准握持插槽高度，消除回收印戳时的浅层相交。
