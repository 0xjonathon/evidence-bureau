1. 金星：在浏览器打开国家航天局《解读金星》，正文可见，核对了自转与公转时长段落。
2. 月球：在浏览器打开科普中国《为什么我们永远看不到月球的“背面”？》，正文可见，核对了“月球背面≠黑暗面”段落。
3. 真空传声：读取中国载人航天工程网《太空上能听到拉马头琴的声音吗？》，正文可见，核对了传播介质段落。

这是对具体来源的抽查，不代表服务器逐条抓取了所有来源全文。原报告仍如实注明“依据搜索摘要”。部分站点在搜索工具中不可读取，但浏览器可以正常打开；未把工具读取失败等同于来源失效。
