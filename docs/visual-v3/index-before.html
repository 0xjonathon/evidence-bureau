A LITTLE FIELD GUIDE

给传闻，一个交代。

  1. 把线索写在纸上。

    一句说法、一个科学疑问，或夹一张截图。图片识别后，请先确认文字再递交。

  2. 侦探带着问题出门。

    元宝多轮检索原始信息与反证，分析模型对照证据，再做第二轮复核。

  3. 只给有依据的回答。

    支持、反驳、有条件或无法判断。来源逐条列出，可以点开复查。找不到，就说不知道。

示例案件展示离线编排的演示报告，不是实时元宝查询。真实调查需要配置服务端接口。报告基于搜索摘要，原文是否仍可访问需以来源页面为准。

BEHIND THE DESK

事务所接入状态

在工程根目录复制 .env.example 为 .env，填入服务端配置并重启 npm run dev。

TENCENTCLOUD_WSA_APIKEY腾讯元宝搜索服务 API KEYLLM_API_KEY · LLM_MODEL用于问题拆解、证据分析与复核LLM_VISION_MODEL可选，用于识别截图中的说法

密钥只保存在本机服务端，不填入网页。未接入搜索时无法进行真实调查；只接入搜索时可查看检索证据，结论保持“无法判断”。
