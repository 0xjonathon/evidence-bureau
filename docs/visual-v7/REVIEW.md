# V7 交互复核（2026-10-25）

## 当前实现

以重新读取的 Claude 修改后工程为起点，保留搜索、探员、档案、证据剧场等业务逻辑；重建桌面运行场景。

- 侦探的解剖学右手托腮、左手敲桌；仪器位于侦探左侧，笔和印章位于右侧。访客自己的笔在委托单右侧。
- 一体仪器为 Blender 4.5.9 建模导出的独立 GLB。顶部扫描床、面向访客的屏幕、独立下方出纸槽、导轨、散热片与紧固件均有几何。旧笔记本、独立键盘、打印机及扫描仪隐藏。
- 委托单在桌上，微光描边和小入口按钮提示点击；进入后相机俯视纸面。输入通过本地中文笔画数据同步墨迹与笔尖；多图添加和移除更新物理纸面纹理。
- 提交先放下访客的笔；侦探自行取纸、抬高、移至扫描床、缓慢放下并松手。屏幕与浮窗消费相同调查事件。
- 新报告从下方通道输出；侦探取出、放到工作区，再按 supported / refuted / mixed / unknown 分别盖章、画叉、写“存在争议”或“证据不足”，放下工具后把报告送回原委托单位置，最后打开正文。

## 实现边界

纸张是薄刚体加受控边缘弯曲；角色采用原始标准蒙皮、身体动画层、双骨 IK 与手指 CCD。不是布料软体或全身布娃娃，也未用旧胶囊关节替换人物。碰撞断言针对桌面、仪器实体及所采样的原生手/前臂蒙皮表面；不能据此推导任意视角、任意用户输入都不存在任何角色自身或衣物交叠。本轮没有重复调用付费搜索，也没有发布线上版本。

Blender MCP 工具在本轮可用工具列表中未暴露；使用本机 Blender 后台生成器完成仪器源与导出，未重新安装插件。
