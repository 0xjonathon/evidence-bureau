# V8 人体动作复核

本轮对应“握笔不能反折、侦探拿放/盖章/写字不能扭曲、处理动作加快”的反馈。保留用户及 Claude 已完成的查证、证据剧场、档案和报告逻辑。

## 实际改动

- 删除手指无约束球关节 CCD。五指使用原生骨骼的局部铰链，限制 MCP/PIP/DIP 与拇指对掌/外展；分别校准三指握笔、印章夹持、捏纸、托腮和敲桌姿态。
- 以“肘部到抓握点”为整体求解，再恢复手腕，消除原来腕部方向反复反馈导致的肘部翻转。写字手腕约 10°，拿纸保持中立，盖章沿垂直印柄对握并限制腕部弯曲；当前路径检查肩部轴向转动不超过约 90°、前臂约 77°。
- 每条前臂加入四个只用于蒙皮的渐进扭转关节，保留原生肩、肘、腕与五指；避免腕部转向在衣袖/肘部集中成一次扭转。独立复制骨骼绑定矩阵，防止多个模型实例共享数组被污染。
- 人物臀部留在座位，工作时由腰背小幅前倾并补偿头部方向，眼神随当前纸张偏转。桌面前沿与两侧形成座位凹口，给腰腿留出空间；器材整体后移 0.40 场景单位。
- 纸张先在身前抬起再移向设备；报告在侦探右侧批注，再短距离送回原委托单位置。抓住、抬起、放下、松手仍与实际纸张物理位置同步。
- 正常播放倍率 1.8：取单扫描约 4.7 秒，出纸、批注及归还约 10.2 秒。提交时以 3 倍书写进度补齐尚未写完的内容，减少额外等笔的时间。

- 盖章使用沿印柄的固定抓握方向，校准拇指与食指的对握间距；逐帧检查皮肤与印柄、球形把手，防止握柄穿手。笔放在实体笔架上，拿起时先握稳再移动，归还时先放稳再松手。
- 委托者拿笔、书写和放笔共用道具实际方向；放下后双手从桌面上方退出。仅对极浅的指腹接触使用可逆蒙皮修正，最大 0.0125 场景单位，骨骼位置保持不变。
